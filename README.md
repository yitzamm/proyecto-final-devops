# Proyecto Final – Introducción a DevOps y Git

## Objetivo

Simular un flujo DevOps completo: código → integración → despliegue.

## Tecnologías

- Git / GitHub

1. Cada cambio se sube en una rama `feature/*`.

2. Se revisa mediante Pull Request.
